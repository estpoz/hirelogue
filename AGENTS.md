# Agent Instructions

## Coding Standards

- Keep code clean, focused, and easy for the next developer to understand.
- Add `MARK` sections in Swift files when they clarify structure.
- Add comments only where they explain context, intent, or non-obvious behavior.

## Planning Before Implementation

- Before generating or changing code, provide an implementation plan.
- Wait for user acceptance before applying code changes.

## Scope Control

- Do not edit unrelated files.
- Keep changes limited to the user's requested task.
